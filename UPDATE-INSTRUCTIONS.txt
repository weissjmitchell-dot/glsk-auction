GLSK Draft Results Update

1. Extract this ZIP on your Windows laptop.
2. In GitHub, open weissjmitchell-dot/glsk-auction on main.
3. Choose Add file > Upload files from the repository root.
4. Drag in the extracted src and tests folders. Commit the changes.
   Keep src/league.js inside src; do not upload the ZIP itself.
5. Let Vercel finish deploying for the website.
6. In Codemagic, start the GLSK iPhone - TestFlight build workflow on main.
7. Once Apple finishes processing, update GLSK in TestFlight.
8. Open Draft > Draft Results > Auction, Supplemental, or Snake.

The new screens read the existing room results and never edit draft records.
Auction results omit undone sales. Supplemental results show selecting and winning teams.
Refresh Results fetches current records. Results use the existing room tables; this does not import past seasons or add a multi-season archive selector.
No database migrations or environment-variable changes are required.
Previous acquisitions and rookie-rights fixes are included.
